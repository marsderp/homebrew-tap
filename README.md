# marsderp/tap

Homebrew tap for Nidi (macOS 14 or later).

```sh
brew install --cask marsderp/tap/nidi
```

Nidi updates itself after that. To remove it and its data:

```sh
brew uninstall --zap --cask nidi
```

The cask version and checksum are updated by Nidi's release workflow. Do not edit `Casks/nidi.rb` by hand.
